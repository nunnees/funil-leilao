# Funil - Páginas

- `/front` — Página principal (FRONT_EUA)
- `/up1` — Upsell 1 (UPSELL_EUA)
- `/up2` — Upsell 2 (UPSELL2_PREVIEW)
- `/dn` — Downsell / Wheel (DOWNSELL_WHEEL)
